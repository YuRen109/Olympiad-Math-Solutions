# <span id="problem"></span>Problem
Let $a,b,c$ be real numbers satisfying $a<b<c$, $a+b+c=6$ and $ab+bc+ca=9$.  
Prove that  

$$0 < a < 1 < b < 3 < c < 4.$$

# Source

[BMO2 1995 Problems](https://bmos.ukmt.org.uk/home/bmo2-1995.pdf)

# Solution


### <span id="claim1"></span>Claim 1 ($0<a<b<c$)

$$0<a<b<c.$$

*Proof.*  

It is apparent that $c>0$, because, otherwise, $if a<b<c \leq 0$, then $a+b+c < 0$.

Now we will prove $b>0$.  
Suppose that $b \leq 0$. Then $a < b \leq 0$, $c = 6 - a - b = 6+\left|a\right|+\left|b\right|$ and 

$$\left|a\right| \left|b\right| = ab = 9 - c(a+b) = 9 - (6- a - b)(a+b) = 9 - 6 (a+b) + (a+b)^2 = (3-a-b)^2 = \left( \left|a\right|+\left|b\right|+3 \right)^2.$$

By [AM-GM inequality](https://en.wikipedia.org/wiki/AM%E2%80%93GM_inequality) we have $\left|a\right| \left|b\right| < \left( \frac{\left|a\right|+ \left|b\right|}{2} \right)^2$

$\square$

By [Claim 1](#claim1) we have that $a=2$ or $a=3$.
