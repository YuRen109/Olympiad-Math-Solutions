# <span id="problem"></span>Problem
Find all triples of positive integers $(a,b,c)$ such that

$$ \left( 1 + \frac{1}{a} \right) \left( 1 + \frac{1}{b}\right) \left( 1 + \frac{1}{c}\right) = 2.$$


# Source

[BMO2 1995 Problems](https://bmos.ukmt.org.uk/home/bmo2-1995.pdf)

# Key Idea


# Solution
Suppose that such a triple of positive integers $(a,b,c)$ exists in [the problem statement](#problem) 
and let $a,b,c \in \text{ℕ}$ satisfy the equation in [the problem statement](#problem).  

Without loss of generality, let $a \leq b \leq c$.

### <span id="claim1"></span>Claim 1 ($a = 2$ or $a = 3$)

$$1 < a \leq 3.$$

*Proof.*  
Suppose $a=1$. Then $1 = \left( 1 + \frac{1}{b}\right) \left( 1 + \frac{1}{c}\right) > 1$, a contradiction.  

Expand $\left( 1 + \frac{1}{a} \right) \left( 1 + \frac{1}{b}\right) \left( 1 + \frac{1}{c}\right)$ we have

$$
2 = \left( 1 + \frac{1}{a} \right) \left( 1 + \frac{1}{b}\right) \left( 1 + \frac{1}{c}\right)
= 1+a^{-1}+b^{-1}+c^{-1}+a^{-1}b^{-1}+b^{-1}c^{-1}+a^{-1}c^{-1}+a^{-1}b^{-1}c^{-1} \leq 1 + 3 a^{-1} + 3 a^{-2} + a^{-3},
$$

or $3 a^{-1} + 3 a^{-2} + a^{-3} \geq 1.$

Since $3 a^{-1} + 3 a^{-2} + a^{-3} < 1$ when $a \geq 4$, we get $a \leq 3$.

$\square$

By [Claim 1](#claim1) we have that $a=2$ or $a=3$.  

### Case where $a=2$
If $a=2$, then $\frac{4}{3} = \left( 1 + \frac{1}{b}\right) \left( 1 + \frac{1}{c}\right) = 1 + b^{-1} + c^{-1} + b^{-1}c^{-1}$.  
Therefore, $\frac{1}{3} = b^{-1} + c^{-1} + b^{-1}c^{-1} \leq 2 b^{-1} + b^{-2}$.  
We have $a = 2 \leq b \leq 6$ since $2 b^{-1} + b^{-2} < \frac{1}{3}$ when $b > 6$.

For $b=6$ we have $1+\frac{1}{c}= \frac{8}{7}$, or $c=7$.    
For $b=5$ we have $1+\frac{1}{c}= \frac{10}{9}$, or $c=9$.  
For $b=4$ we have $1+\frac{1}{c}= \frac{16}{15}$, or $c=15$.  
For $b=3$ we have $1+\frac{1}{c}= 1$, a contradiction since no $c \in \in \text{ℕ}$ satisfy this equation.  
For $b=2$ we have $1+\frac{1}{c}= \frac{8}{9}$, a contradiction since no $c \in \in \text{ℕ}$ satisfy this equation.
